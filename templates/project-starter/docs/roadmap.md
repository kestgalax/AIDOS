# Roadmap

## Milestone 0: Product Intent

Goal: clarify why the project exists and what success means.

## Milestone 1: Architecture Decision

Goal: decide the initial architecture and runtime stack through ADRs.

Exit criteria:

- `docs/decisions/ADR-002-runtime-stack.md` is Accepted.
- `docs/architecture.md` reflects the chosen stack.

## Milestone 1.5: Dev Environment

Goal: define the local development environment for the accepted stack.

Checklist:

- Local runtime and package manager are selected.
- `ops/environments.md` documents local/test environments.
- `ops/ci.md` documents governance checks for CI.
- First feature can be implemented without stack ambiguity.

## Milestone 2: First Feature

Goal: deliver the first traced feature through AIDOS workflow.
