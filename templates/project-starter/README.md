# New AIDOS Project

This project uses AIDOS to preserve product intent, architecture, decisions, execution rules, and review governance.

## Start Here

1. Read `docs/product-intent.md`.
2. Read `docs/roadmap.md`.
3. Read `docs/architecture.md`.
4. Review `docs/decisions/`.
5. Follow the project lifecycle in your AIDOS clone at `docs/onboarding-project-lifecycle.md`.

AI agents must start with `AGENTS.md`.

## AIDOS Tooling

Set `AIDOS_ROOT` to the path of your cloned AIDOS repository, or update `aidos.config.json`.

```bash
npm run aidos:validate
npm run aidos:trace
npm run aidos:review
```
